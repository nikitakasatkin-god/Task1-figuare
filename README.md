# Task 13. Компоновщик

## Описание

Это приложение на JavaFX позволяет пользователю рисовать различные геометрические
фигуры на холсте. Приложение реализует паттерн "Компоновщик" для создания графического объекта
и использует класс `Composite` для агрегации элементарных объектов.

## Требования

- Java 11 или выше
- JavaFX SDK
